- In Images you'll find images we used in code (not all images were used)

- In ImageProcessing you'll find two files. ImageCompression_SVD.py has the code related to SVD operations on
  images, and ImageProcessing.ipynb has the code related to geometric transformations and convolutions.
  You can copy paste the code from ImageCompressions_SVD.py to your visual studio code, and make sure to download
  any images you will be using into your local folder. For ImageProcessing.ipynb, you can see the outputs within
  file. If you want to run the code, make sure to copy paste all the import statements in the first cell, and then
  copy the code from the other cells to your liking since each cell has a separate transformation being applied to
  the image.

- In ImageCompression_SVD you'll find the compression code accompanied by options to do just one compression, 
  multiple, bad vs good comparison and grey scale code. (remove quotes surrounding sections of code to run 
  the desired output).
